# Certificates Directory

Place your official certificate PDF or image files in this directory:
- `IBM_Certificate.pdf` (or .png/.jpg)
- `Microsoft_Excel_Certificate.pdf`
- `Python_Data_Science_Certificate.pdf`
- `DecodeLab_Internship_Certificate.pdf`
- `AINEX_VisionX_Certificate.pdf`

You can also customize the URLs or external links directly in:
`src/data/portfolioData.ts` under the `certifications` array.
